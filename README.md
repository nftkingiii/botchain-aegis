# Aegis

Aegis anchors decision evidence on BOT Chain. This repository contains the verified `AegisAnchor` contract, its tests, and deployment script.

Testnet deployment and explorer proof: [BOTCHAIN_TESTNET.md](BOTCHAIN_TESTNET.md).

This repository publishes the contract layer only. No public web app URL or mainnet deployment is claimed.

```sh
forge build
forge test
```
